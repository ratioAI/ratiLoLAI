Built-in music for the Clips editor. All three loops are synthesized by `scripts/make-music.py`
(sine, saw and noise generators; no samples, no borrowed melodies) and dedicated to the public
domain: CC0 1.0, https://creativecommons.org/publicdomain/zero/1.0/

| File | Title | Tempo |
|---|---|---|
| nebula-drift.m4a | Nebula Drift | 80 BPM, 24 s loop |
| pentakill-rush.m4a | Pentakill Rush | 140 BPM, 27 s loop |
| victory-lap.m4a | Victory Lap | 110 BPM, 17 s loop |

To change or add a loop, edit the script and run `python3 scripts/make-music.py`.
